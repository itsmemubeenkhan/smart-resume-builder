# AI Resume Builder

Professional Flutter application for Resume Building and Job Tracking.

## Getting Started

This project is a starting point for a Flutter application.

## Documentation

For full product details and configuration instructions, please open **`documentation.html`** in your browser.

## Quick Setup

1.  **Install Flutter:** Ensure you have Flutter installed.
2.  **Get Dependencies:**
    ```bash
    flutter pub get
    ```
3.  **Configure Ads:**
    - Open `lib/core/config/ad_config.dart`
    - Replace the Test Ad Unit IDs with your own AdMob / Facebook Audience Network IDs.
4.  **Run the App:**
    ```bash
    flutter run
    ```

## Features

-   **Resume Builder:** Create professional resumes.
-   **Job Tracker:** Track application status (Applied, Interview, Offer).
-   **Monetization:** Dual Ad Network support (AdMob & Facebook Audience Network) with a smart switcher.
-   **Offline First:** Uses Hive for local storage.
